# 止损与成交规则 v0.1

状态：待用户审阅，尚未生效。适用对象：币安普通美股/ETF 的本地模拟实验；不包含 bStocks、杠杆、期权或加密货币。真实 API 数据与本地模拟交易必须分别标注。

## 建议采用的第一版

| 项目 | 建议 |
| --- | --- |
| 交易时段 | 仅美股常规时段，按 America/New_York 日历；不使用盘前、盘后或隔夜交易 |
| 仓位 | 同时最多一个仓位，单仓不超过初始实验资金的 10% |
| 入场 | 两类独立证据成立后，先确定入场、止损、目标、数量和全部费用 |
| 止损 | 放在交易逻辑失效的位置，如已确认支撑下方；不能为了买入而人为缩小止损距离 |
| 止盈 | 候选目标按至少 1.5 倍净风险评估；实际价格结构不支持时放弃 |
| 时间退出 | 入场后 30 分钟重新评估；无延续且逻辑转弱时退出，不能无限等待 |
| 尾盘 | 常规收盘前 45 分钟停止持有新风险，前 15 分钟完成日内退出核对；提前收盘按同样相对时间调整 |
| 监控 | 有模拟仓位时建议每 5 秒采集报价，每次采样检查止损；六次研究任务不承担连续止损职责 |
| 数据断线 | 最近成功采样超过 15 秒则停止新增仓位，记录数据缺口；恢复后先核对再继续 |

以上 30 分钟、1.5 倍、5 秒和 15 秒均为实验初版参数，不是经过验证的最佳参数。连续监控尚未实现，草案未批准前不启动模拟持仓。

## 止损与数量

只做多，记入场价为 E、止损价为 S，要求 E > S > 0。所有金额和数量使用 Decimal。

单笔风险预算 = 初始资金 × 0.5%。数量应满足：

```text
数量 × (E - S) + 预计往返费用 + 滑点预留 <= 单笔风险预算
数量 × E <= 初始资金 × 10%
买入名义金额 + 买入费用 <= 可用实验现金
```

数量按股票接口 stepSize 向下取整，再检查 minQty、minNotional、fractionable 和当前 tradability。取整后不满足条件则记“不交易”，不得向上补量突破风险限制。费用取自实际账户适用费率，尚未确认时不假定为零。

## 模拟成交

1. 买入使用决策完成后收到的首个有效卖一价，卖出使用买一价，另计滑点和费用；禁止用决策前价格回填成交。
2. 只有下次报价能覆盖模拟数量时才记全部成交；数量不足则等待或按可观察数量部分成交，不能默认全部成交。
3. 买一价 <= 止损位时触发模拟卖出。成交按触发后首个有效买一价及滑点计算；跳空低于止损位必须记录额外损失。
4. 限价单“触价”不等于成交。没有足够交易或盘口证据时保持未成交，不据一次报价编造排队优先级。
5. 缺失区间若另有可信逐笔或分钟数据，可重放路径；同一根 K 线同时触及止损和目标而顺序不明时，采用止损先触发，并标注该假设。
6. 没有缺失区间数据时，将结果标为“无法完整重建”。可以按恢复后的首个可执行报价模拟退出，但不能声称已在缺口内止损。
7. 将价格损益、平台费、兑换成本、其他费用和净损益分列，保留来源时间及采样时间。

币安股票 quote 接口文档示例没有交易所报价时间字段。收到响应的时间不能单独证明报价新鲜；需验证常规交易时段的连续数据和更新时间依据。验证完成前只记报价样本，不据此开仓。

## 每日停止条件

- 当日已实现净亏损加剩余仓位的预计退出风险达到初始资金的 2%，停止新增交易。
- 当天连续两次触发止损，停止新增交易。
- 账户、报价、订单状态不一致，先处理已有风险并暂停新增交易。
- 不摊平亏损、不提高风险额度追赶收益；初版不允许隔夜。

已实现净亏损按 max(0, -当日已实现净损益) 计算，未平仓退出风险须包含尚未支付的退出成本，避免重复计入已支付费用。

## 20 USDT 实验如何处理

仍保留 20 USDT 初始实验资金、2 USDT 单仓上限和 0.10 USDT 单笔风险。若实际最小订单或费用超过这些限制，现实约束版本的正确结果是“不交易”。用户愿意承担实验成本，不代表交易所会接受低于最小金额的订单。

如希望测试成交和止损代码，可另建带有固定输入的离线测试用例；它不计入真实行情实验业绩。扩大虚拟资金或改变风险额度应另行明确，不在此草案中自动调整。

## 与实盘的边界

官方股票下单 API 目前列出 MARKET 和 LIMIT，不应假设支持 Spot 的 STOP_LOSS 或 OCO。每 5 秒轮询也不是券商托管止损，程序、网络或电脑中断均可能导致退出延迟。本次不实现实盘下单和自动接受股票服务条款。

未来如单独实现普通股票实盘，订单参数应显式设置 tokenize=false。API 的接收确认、实际成交、部分成交和撤单必须分开记录。

## 请审阅的重点

是否接受：仅常规时段、一个仓位、30 分钟复评、至少 1.5 倍净风险目标、5 秒报价采样，以及费用不满足风险预算时不交易。批准前，本文件只供参考。
