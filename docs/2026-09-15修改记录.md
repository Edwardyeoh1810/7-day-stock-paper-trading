## 已完成修改

### GitHub Actions

- 新增 `.github/workflows/paper-trading-observation.yml`。
- 支持 GitHub 手动触发；手动触发使用 `--manual`。
- 按 2026 年 9 月 Central 夏令时配置每天六次 UTC cron。
- Python 运行器仍会根据 `routines/schedule.json` 二次检查实验日期和允许窗口。

- 同一时间只允许一个观察任务运行，最长运行十分钟。
